# Pain001 v0.0.73

This coordinated release ships with pain001-lsp, pain001-loader-xlsx and
pain001-loader-mt101 at 0.0.73. pain001-mcp 0.0.73 is already published;
it went out early as a pyjwt security release.

**Generated XML changes for some CSV input.** v0.0.72 prefixed CSV cells
starting with `=`, `+`, `-` or `@` with a single quote, as a defence
against spreadsheet formula injection (CWE-1236). pain001 writes
ISO 20022 XML, which no spreadsheet evaluates, so the prefix protected
nothing and corrupted legitimate payment data such as `+44` phone numbers
and `-INV` references. Ingress now preserves the supplied value, as
v0.0.71 did, and neutralisation is opt-in through the `sanitize_formula`
parameter of `load_csv_data` and `load_csv_data_streaming`. See
ADR-0008.

The Business Application Header envelope and XML-DSig signature are now
applied in memory before the single write, instead of re-reading and
re-writing the generated file. The `Context` singleton and the REST
`JobManager` are guarded by re-entrant locks against races during
concurrent start-up and polling.

Release SBOMs now describe pain001's own runtime dependencies. The
locked pyjwt (2.15.1) and urllib3 (2.8.0) clear thirteen CVEs reported
by pip-audit. Dependency updates include ruff 0.17.1, pydoclint 0.11.1,
mcp 2.3.0, fakeredis 2.40.0, holidays 0.107 and hypothesis 6.170.5.
