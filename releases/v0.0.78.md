# pain001 v0.0.78

In progress. The faces of ADR-0005 (Phase B), and the faces on every
surface the suite offers.

## Faces

- `pain001.faces` and `pain001 face`: a pain.001 document projected
  into UK Open Banking v4.0.1, Berlin Group NextGenPSD2 v1.3.16 or ISO
  20022 element names, with a loss report of every source element not
  carried.

## Faces on the REST API, the MCP server and the language server

- REST: `GET /api/v1/faces` and `POST /api/v1/faces/{face}`, the
  document as XML text in the body, the payload and loss report back.
- Every surface takes the document through `project_face_text`: XML
  text only, never a server path, no entities, at most 10 MiB.
- MCP and the language server: planned; filled in as each lands.
