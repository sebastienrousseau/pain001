# Pain001 v0.0.72

This coordinated release ships with pain001-mcp, pain001-lsp,
pain001-loader-xlsx and pain001-loader-mt101 at 0.0.72. This release
introduces comprehensive ISO 20022 Schematron business rule evaluation,
enabling declarative assertions against EPC, SEPA, and CBPR+ rulebooks
beyond base XSD structural constraints.

The release introduces automated formula injection shielding across
both batch and streaming CSV ingestion, neutralizing spreadsheet formula
injection vectors (CWE-1236) by properly escaping formula trigger characters
at ingestion time.

Additionally, this release implements full support for ISO 20022 Business
Application Headers (BAH head.001.001.03 and head.003.001.01) and W3C XML
Digital Signatures (XML-DSig RSA-SHA256) with exclusive canonicalization,
along with an embedded Prometheus metrics engine emitting standard performance
and volume quantiles under the `/metrics` endpoint on pain001[api].

Optional native acceleration hooks integrating `pain001-fast` provide
sub-25ns financial validation for IBAN, BIC, and ISO character set verification
when installed, while retaining full pure-Python fallbacks and preserving 100%
line and branch test coverage across the entire test suite.

Dependency updates include diff-cover 10.6.0, ruff 0.16.9, hypothesis 6.168.3,
and GitHub Actions CodeQL bundle 4.38.2. Release artifact provenance is attested
via SLSA Level 3 workflows.
