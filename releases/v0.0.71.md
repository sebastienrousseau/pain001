# Pain001 v0.0.71

This coordinated release ships with pain001-mcp, pain001-lsp,
pain001-loader-xlsx and pain001-loader-mt101 at 0.0.71. Install the optional
`rules` extra for request-local CEL policies and the `upload` extra for
explicit SFTP delivery. CLI and REST validation and generation, including
background jobs, apply the selected policies without changing global state.

Correction suggestions are deterministic and review-only: financial fields
including accounts, amounts and currencies are never silently rewritten.
SFTP delivery verifies trusted host keys, publishes through unique staging
files, refuses to overwrite an existing destination and supports hash-based
retry reuse. Delivery is not bank acceptance or settlement.

Registered loaders and scheme overrides now participate consistently in
streaming and whole-file dispatch. The plugin API version and generated XML
contract are unchanged. Issue #179 remains open for independent external
plugin-author validation; this release does not claim that validation occurred.

The release also repairs documentation deployment, exercises every numbered
example and benchmark, expands API and optional-dependency regression tests,
and refreshes dependency and supply-chain pins. The coverage gate remains
100% line and branch; it is not proof of exhaustive functional correctness.

Four maintainer-accepted security exceptions remain risks, not fixes. Their
owner, next review and expiry are recorded in
`docs/security-exceptions.json` and enforced by release preflight.

The published release body includes SHA-256 checksums computed from the actual
release artifacts, with a matching `SHA256SUMS` asset. Candidate checksums must
be recomputed from the merged release commit before signing or publishing.
