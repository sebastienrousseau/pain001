# pain001 v0.0.90

## Highlights ⭐️

* **A fresh server no longer fails its first parallel requests**: a
  just-started `pain001 serve` could answer concurrent requests with
  HTTP 500, "partially initialized module 'xmlschema'". `lazy_module`
  now waits for an import another thread has in progress, as an
  `import` statement does.
* **The GitHub Action is easier to find**: it is listed as "ISO 20022
  Payment File Check (pain001)", its description names pain.001,
  pain.008, payment XML, SEPA, CBPR+ and FedNow, and the README shows
  it in a workflow. The `uses: sebastienrousseau/pain001@v...` path is
  unchanged.
* **In lockstep with the pain001 suite**, which follows at 0.0.90.
