# pain001 v0.0.74

## Highlights ⭐️

* **CSV values reach the XML as supplied again**: v0.0.72 prefixed CSV cells starting with `=`, `+`, `-` or `@` with a single quote, which corrupted real payment data such as `+44` phone numbers and `-INV` references in XML no spreadsheet ever evaluates. Ingress keeps the value, as v0.0.71 did, and neutralisation is opt-in through `sanitize_formula` (ADR-0008). This changes the generated XML for such input.
* **No affected certifi can resolve**: `pain001[otel]` now requires `certifi>=2026.10.19` (GHSA-6q48-6c7w-9gw2), the lock and every hash-pinned tool set are past the fix, and the Security workflow audits each hash-pinned file.
* **The suite moves as one**: every member, loaders included, requires the core at its own version, the release preflight refuses a suite floor that differs from the release, and the nightly check also reports a version bumped in the tree and never released.
* **In lockstep with the pain001 suite at 0.0.74**: the core releases first and `pain001-lsp`, `pain001-loader-xlsx`, `pain001-loader-mt101` and `pain001-mcp` follow at 0.0.74. The core skips 0.0.73, which `pain001-mcp` had already published on its own as a pyjwt security release.

## Details

The Business Application Header envelope and XML-DSig signature are
applied in memory before the single write, instead of re-reading and
re-writing the generated file. The `Context` singleton and the REST
`JobManager` are guarded by re-entrant locks against races during
concurrent start-up and polling. Release SBOMs describe pain001's own
runtime dependencies, and the locked pyjwt (2.15.1) and urllib3 (2.8.0)
clear thirteen CVEs reported by pip-audit.

New gates: per-function complexity ceilings (cyclomatic 10, cognitive
15, Halstead 30, 60 lines) against a baseline that only shrinks, and the
four open CodeQL alerts are fixed. Tags are signed as `pain001 v<version>`
and the GitHub release is titled `pain001 <version>`. `CITATION.cff`
now validates against CFF 1.2.0, and the README follows the portfolio
template with a rendered demo of the Quick Start.

Dependency updates include ruff 0.17.1, pydoclint 0.11.1, mcp 2.3.0,
fakeredis 2.40.0, holidays 0.107 and hypothesis 6.170.5.
