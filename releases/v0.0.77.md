# pain001 v0.0.77

## Highlights ⭐️

* **pain.008 creditor and debtor in the right place**: pain.008.001.02 and .08 now fill `Cdtr`, `CdtrAcct` and `CdtrAgt` from the `creditor_*` columns and each transaction's `Dbtr`, `DbtrAcct` and `DbtrAgt` from the `debtor_*` columns. They were reversed. Reported in #346 by @mrestivill.
* **Check your direct-debit input**: if you swapped your own columns to get correct output, swap them back. The bundled samples were relabelled and render the same XML as before.
* **In lockstep with the whole suite**: pain001-mcp, pain001-lsp, pain001-loader-xlsx and pain001-loader-mt101 ship 0.0.77 too.

## Details

The `api` extra requires `fastapi >= 0.162.0`. Development and docs
tooling moved to current releases (ruff, complexipy, mutmut, pydoclint,
pandas for tests, Sphinx extensions and theme). pain.001 output, the
CLI and the REST API are unchanged from 0.0.76.
