# pain001 v0.0.91

## Highlights ⭐️

* **Every Dependabot update in one release**: setup-java 6.3.0,
  markdown-it-py 4.3.0, ruff 0.17.6, sphinx-design 0.8.0, myst-parser
  5.2.0, complexipy 9.0.0 and four smaller updates, with the docs,
  release, API and complexity locks moving alongside `poetry.lock`.
* **complexipy 9 without loosening the complexity gate**: functions
  the new scorer rated higher were restructured instead of being
  absorbed into the baseline, which only shrinks. No output changes.
* **Local gates survive a test run**: `make type` and `make lint` no
  longer trip over the scratch module a test leaves in `pain001/tmp/`.
* **In lockstep with the pain001 suite**, which follows at 0.0.91.
