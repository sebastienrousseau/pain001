# pain001 v0.0.76

## Highlights ⭐️

* **Retired docs pages redirect**: The `pain001.constants.html` and `pain001.templates.pain.*.html` pages that Search Console reported as 404 now redirect to the package pages that replaced them, and the docs build fails if a redirect source is still built or a target is not.
* **A sitemap of indexable pages only**: Every docs.pain001.com page names its canonical URL, the viewcode sources, search and index pages are `noindex, follow`, and a generated `sitemap.xml` lists only the indexable pages, with `robots.txt` pointing at it.
* **msgpack advisory closed**: The dev group requires `msgpack >= 1.2.3` (CVE-2026-114613), and `poetry.lock` moves msgpack 1.2.1 to 1.2.4.

## Details

`scripts/check_docs_sitemap.py` checks the built docs in `docs.yml` and
in `make docs`: every sitemap URL is a built, indexable page with a
canonical link to itself. The library, CLI and REST API are unchanged
from 0.0.75.
