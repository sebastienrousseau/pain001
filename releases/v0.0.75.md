# pain001 v0.0.75

## Highlights ⭐️

* **Python 3.11 is the floor**: Python 3.10 support is removed across the pain001 suite. 3.10 reaches upstream end-of-life in October 2026 and current `hypothesis` releases need 3.11. pip keeps a 3.10 interpreter on 0.0.74, and CI tests 3.11 to 3.14.
* **filelock, setuptools and OpenTelemetry advisories closed**: The dev group requires `filelock >= 4.2.1`, the bootstrap requirements move setuptools to 84.1.0 (GHSA-xmj3-9gf7-h52w), and the lock moves OpenTelemetry to 1.45.1 (CVE-2026-114603).
* **FastAPI 0.161.1 for the `api` extra**: The extra requires `fastapi >= 0.161.1`, and the hash-pinned API requirements add `opentelemetry-api` 1.45.1, which that FastAPI release depends on.
* **Second release signing key**: `KEYS.asc` trusts `SHA256:kIOPAavp1TCEauTr1tTIN3cv+tSs6F9m/4lZjuM9tqk` (rousseau-mbp-m1), so release tags can be signed on either maintainer machine. Each key line carries its fingerprint.

## Details

Dropping 3.10 removes the `tomli` fallbacks, the Python markers on
`pip-audit` and `filelock`, and the `make sec` version guard, so
pip-audit runs on every supported Python. ruff and mypy target 3.11:
the code uses `datetime.UTC`, and the REST API's `JobStatus`,
`DataSourceType` and `MessageType` are `enum.StrEnum`, with the same
values and JSON form. This rise was not announced a release ahead as
ADR-0004 asks; the ADR records the exception.

The maintainer re-accepted the four Scorecard exceptions on
2026-10-26, with review due 2026-12-23 and expiry unchanged on
2026-12-24, and `SECURITY.md` now states those dates.

Dependency updates include paramiko 5.1.0 for the `upload` extra,
ruff 0.17.2, the `types-paramiko` stub, and the GitHub Actions group
(setup-python 7.1.0, pypi-publish 1.14.3, codeql-action 4.39.1,
docker/login-action 4.7.0).
