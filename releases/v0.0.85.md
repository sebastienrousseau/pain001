# pain001 v0.0.85

## Highlights ⭐️

* **Exactly-once SFTP downloads**: Download bank replies with a local ledger
  committed before a remote file is deleted or moved. File and byte limits and
  explicit host-key trust remain part of the download contract.
* **Payment and account status**: Read pain.002 replies with the status
  command and return exit status 3 for a rejection. The camt extra adds
  camt.052, camt.053 and camt.054 report reads through camt053.
* **A release evidence pack**: Each release attaches a bundle containing data-
  handling and licence information, a security questionnaire, maintenance and
  security policies, the release SBOM, provenance and checksums.
* **Self-service integration**: Publish private bank-profile guidance,
  integration recipes and the maintenance policy. Acknowledgement windows are
  goals with no SLA, and the project provides its software and evidence
  without a commercial offer.
