# pain001 v0.0.88

## Highlights ⭐️

* **Five SDKs join the family**: The Go, Java, Rust, .NET and C++ SDKs
  release at 0.0.88 with the rest of the suite, and `docs/ecosystem.json`
  lists all fourteen repositories. `make ecosystem-check` now verifies each
  SDK's signed tag and release assets and its registry: the Go module
  proxy, the Maven Central jar against the release checksum, crates.io and
  NuGet.
* **Two advisories cleared**: `soupsieve` 4.1 and `opentelemetry-api`
  1.45.2 are now the floors, clearing `GHSA-4j63-6c4x-wfg4`,
  `GHSA-mmhr-3c5m-f64f`, `GHSA-6655-6qjp-jx7x`, `GHSA-7g44-g9rc-x53w` and
  `GHSA-mf5v-w3w3-f6cg`.
* **Cleaner documentation for search engines**: docs.pain001.com no longer
  publishes raw reStructuredText copies beside the rendered pages.

## Release verification

Core publishes before its companions. The full publication audit verifies
all fourteen repositories, their signed releases, registry artifacts,
images, MCP Registry record and deployed website before the suite is
complete.
