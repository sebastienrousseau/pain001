# pain001 v0.0.89

## Highlights ⭐️

* **The deprecated JSON flags are gone**: `--json` on `versions`,
  `inspect` and `plugins list`, and `--scheme-format json` on `generate`
  and `validate`, now exit 2 with "No such option". Use `--format json`;
  the scheme result is the `scheme` field of its one JSON object.
* **Signature checks no longer crash on hostile input**:
  `verify_signature` refuses a document nested too deeply or with an
  oversized text node with a reason instead of raising, and a signature
  that does not verify now says "invalid" rather than ending at a colon.
* **Mutation testing that only moves forward**: the weekly full run is
  split into shards so it finishes and reports a score again, the floor
  rises to 85%, and a per-function ratchet fails any run where more
  mutants survive than `mutation-baseline.json` records.
* **The GitHub Action can be listed on the Marketplace**: its description
  now fits the Marketplace's 125-character limit, and a test keeps it
  there.
