# pain001 v0.0.80

## Highlights ⭐️

* **REST jobs no longer share an output file (GHSA-vv3x-jpvc-w468)**: every generation through the REST API writes its own `<message_type>-<random>.xml`. With the old shared `<message_type>.xml`, a later job overwrote an earlier one and the earlier job's download returned the later caller's payment file. Affects 0.0.48 to 0.0.79; the CLI and the library were not affected.
* **In lockstep with the whole suite**: pain001-mcp, pain001-lsp, pain001-loader-xlsx and pain001-loader-mt101 ship 0.0.80 too.

## Details

This is a security release with one change. Upgrade any deployment that
runs `pain001 serve` and is used by more than one caller. Read the
generated file's path from the response (`file_path`) or the job result
rather than building `<message_type>.xml`. Generated XML is unchanged.
